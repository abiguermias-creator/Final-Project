# Study Planner Web Application

## Project Description
This is a simple Study Planner web application that helps students organize their study tasks.
Users can add tasks, mark them as completed, and delete them.
All tasks are saved using browser localStorage so they remain even after refreshing the page.



##  Features
- Add new study tasks
- Mark tasks as completed using a checkbox
- Delete tasks
- Tasks persist using localStorage
- Simple and clean user interface
- Multi-page website (Home, About, Contact)



##  Technologies Used
- HTML
- CSS
- JavaScript (Vanilla JS)
- Browser LocalStorage
- Git & GitHub
